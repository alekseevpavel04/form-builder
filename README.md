# form-builder

Сервис форм отклика: менеджер собирает форму в админке и публикует её по ссылке, студент заполняет, менеджер смотрит ответы и воронку заполнения.

В работе. Инструкция по запуску появится вместе с кодом.

## Что собирает аналитика

Случайный id сессии, который браузер хранит в localStorage, тип события (`view`, `start`, `field_completed`, `submit`), id поля для `field_completed` и время приёма на сервере. Содержимое полей, нажатия клавиш, IP и user agent не собираются.
